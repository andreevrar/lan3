# ТВ-пульт: приложение на ТВ раздаёт страницу пульта по домашнему Wi-Fi

Как это работает:

```
телефон (браузер) ──http + WebSocket по домашнему Wi-Fi──▶ приложение на ТВ (веб-сервер на порту 8080)
                                                                │
                                                    ADB на самого себя (127.0.0.1:5555):
                                                      постоянный помощник мгновенно вставляет нажатия
                                                    + служба спец. возможностей (ввод текста, запасной путь)
```

Ни интернета, ни брокера, ни GitHub Pages не нужно. Телефон и ТВ просто должны быть в одной сети Wi-Fi (ТВ может быть и по кабелю в том же роутере). Вне дома пульт не работает: это сделано намеренно.

## Что внутри

- `app/` — Android-приложение (Kotlin). Фоновая служба с веб-сервером и экран с адресом и кодом.
- `app/src/main/assets/index.html` — страница пульта, её раздаёт само приложение. Вкладки: **Пульт**, **Клавиатура**, **Связь**.
- `app/src/main/java/app/tvremote/WebServer.kt` — встроенный HTTP + WebSocket сервер (без внешних библиотек).
- `.github/workflows/build.yml` — сборка APK на GitHub (ставить Android Studio не нужно).

## Установка

1. Создайте репозиторий на GitHub и загрузите в него всё содержимое этой папки.
2. **APK:** вкладка Actions → *Build APK* (запускается сам после загрузки, либо кнопкой *Run workflow*). Готовый файл `tv-remote.apk` лежит в артефактах запуска, а также в Releases → «Последняя сборка».
3. Скопируйте `tv-remote.apk` на флешку и установите на ТВ (нужно разрешение на установку из неизвестных источников).
4. Запустите приложение. На экране ТВ появится запрос **«Разрешить отладку по ADB?»**. Выберите **«Всегда разрешать»**. После этого приложение само включит себе службу специальных возможностей.
5. На экране ТВ будут показаны **адрес** (например, `http://192.168.1.45:8080`), **код** и **QR-код**. Проще всего навести камеру телефона на QR: откроется страница, код подставится сам. Вручную: откройте адрес в браузере телефона, на вкладке «Связь» введите код и нажмите «Подключиться». Индикатор сверху станет зелёным.
6. Добавьте страницу на главный экран телефона (меню браузера → «Добавить на главный экран»), и пульт будет открываться одним нажатием.

Адрес ТВ в сети может поменяться после перезагрузки роутера. Чтобы он не менялся, закрепите за ТВ постоянный IP в настройках роутера (раздел DHCP, «резервирование адреса» или «привязка по MAC»). Код при этом запоминается в браузере, вводить его заново не придётся.

**Автозапуск.** Пульт поднимается несколькими независимыми способами: сигнал включения ТВ, служба спец. возможностей (сторож раз в 20 с), будильник раз в минуту, проверка при пробуждении ТВ/смене сети, самопроверка веб-сервера (если порт «умер» — перезапускается) и маленький сторож в самой системе ТВ (ставится через ADB, перезапускает приложение раз в 30 с, даже если его закрыли). На экране приложения видно, чем и когда оно было запущено в последний раз ("Запущено: … — причина"). Если на ТВ есть «Автозапуск приложений» или «Экономия энергии», разрешите автозапуск для «ТВ-пульт». Один раз после установки запустите приложение вручную.

**Ввод текста.** Пробуются по очереди: SET_TEXT, вставка через буфер (спец. возможности), клавиши через помощника, ADB-команды. Результат последней попытки показан на вкладке «Клавиатура» и на экране ТВ ("Ввод текста: …").

Если приложения нет в списке программ на ТВ, запустите его из файлового менеджера или командой `adb shell monkey -p app.tvremote 1`. Дальше приложение стартует само при включении ТВ.

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| Страница на телефоне не открывается | Проверьте, что телефон и ТВ в одной сети. В «гостевой» сети роутеры часто запрещают устройствам видеть друг друга («изоляция клиентов»), включите обычную сеть. Адрес берите с экрана ТВ, он может поменяться. |
| «Неверный код» | Сверьте код с экраном ТВ. Если нажимали «Сгенерировать новый код», введите новый. |
| «Нет связи с ТВ» | Приложение не запущено, ТВ выключен либо в режиме ожидания с отключённой сетью. В таком режиме пульт ТВ не разбудит. |
| На экране ТВ «Сервер: ошибка…» | Порты 8080–8089 заняты другим приложением. Перезапустите службу или перезагрузите ТВ. |
| На экране ТВ «ADB: нет» | В настройках для разработчиков включите отладку по ADB (по сети). Приложение подключается к `127.0.0.1:5555`. Затем нажмите «Перезапустить службу» и подтвердите запрос. |
| Кнопки с задержкой | На экране ТВ в строке «Быстрые кнопки» должно быть «да». Если «нет», приложение шлёт каждое нажатие отдельной командой `input keyevent` (это медленно): нажмите «Перезапустить службу» и подтвердите запрос ADB. Если всё равно «нет», у ТВ закрыт доступ к системе ввода, это зависит от прошивки. |
| Кнопки не нажимаются, но ТВ «на связи» | Нужен ADB или «Спец. возможности». Без ADB работают только Назад, Домой, стрелки (двигают фокус) и OK (нажимает выбранное). |
| Текст не вводится | Сначала выберите поле ввода на ТВ стрелками и OK (чтобы в нём был курсор). Включите «Печатать сразу»: страница шлёт поле целиком, ТВ заменяет текст. Латиницу приложение умеет вводить тремя способами (спец. возможности, клавиши, буфер обмена), кириллицу двумя (спец. возможности и буфер обмена), и само переключается между ними. |
| Русский текст не вводится | Нужны «Спец. возможности: включены» (кнопка «Включить спец. возможности через ADB» в приложении). Через ADB проходит только латиница. |

## Безопасность

Сервер слушает только то, что приходит из вашей сети. Доступа из интернета нет, пока вы сами не пробросите порт на роутере (не делайте этого).

Защита от посторонних в вашей сети: страницу может открыть любой, но управлять ТВ можно только с кодом (12 символов). Неверный код не пускает и задерживает ответ на секунду. Приложение принимает только фиксированный список кнопок и ввод текста, произвольную команду выполнить нельзя. Соединения со страниц, открытых не с самого ТВ (чужие сайты), отклоняются. Если код попал не туда, нажмите на ТВ «Сгенерировать новый код».

Связь идёт по обычному `http`, без шифрования. Для домашней сети это нормально, но в общей сети (общежитие, офис, кафе) с кодом лучше не работать.

## Протокол (для доработок)

Страница: `GET /`. Команды: WebSocket `ws://<адрес-тв>:<порт>/ws`.

Первое сообщение после соединения обязательно авторизация, иначе ТВ закроет соединение через 8 секунд:

- `{"t":"auth","c":"abcdefghijkl"}` — ответом придёт статус; при неверном коде придёт `{"t":"denied"}` и соединение закроется.

Дальше JSON-сообщения:

- `{"t":"key","k":"UP"}` — кнопка (список в `Keys` в `Config.kt`: UP, DOWN, LEFT, RIGHT, OK, ENTER, BACK, HOME, MENU, VOL_UP, VOL_DOWN, MUTE, CH_UP, CH_DOWN, POWER, SLEEP, WAKEUP, PLAY_PAUSE, REWIND, FF, NEXT, PREV, DEL, SPACE, SEARCH, SETTINGS, INFO, 0–9)
- `{"t":"text","v":"привет","m":"replace"}` — заменить текст в поле ввода целиком (`"m":"append"` — дописать)
- `{"t":"ping"}` — попросить ТВ прислать статус. Страница шлёт его раз в 15 секунд; без сообщений 60 секунд ТВ закрывает соединение.

Ответ ТВ (приходит при входе, на ping и при изменении состояния): `{"online":true,"adb":true,"acc":true}`.

## Голосовой ввод через телефон

Вкладка «Голос» заменила клавиатуру. В приложении на ТВ нажмите «Включить голосовой ввод через микрофон телефона» (нужен ADB). После этого, когда приложение на ТВ запрашивает распознавание речи (значок микрофона), страница на телефоне сама откроет вкладку «Голос», телефон вздрогнет и начнёт слушать (если запись не началась сама, нажмите «Говорить»). Распознанный текст возвращается в приложение на ТВ как результат распознавания. Если голос в приложении ведёт себя странно, выключите кнопку в приложении: настройка вернётся к прежней. Не работает в приложениях со своим собственным распознаванием (например, у голосового помощника Яндекса).

## Переподключение после выключения ТВ

Страница на телефоне сама переподключается: таймаут подключения 6 с, проверка связи каждые 5 с, повтор каждые 3 с, а также при возврате в браузер или появлении сети. Тап по строке состояния — переподключиться сразу. Если у ТВ после выключения меняется IP-адрес, закрепите за ним постоянный адрес в настройках роутера (DHCP-резервирование).
